# Домашняя библиотека v2.1 — исправления

- Автоматическое предварительное определение языка OCR по текстовому слою PDF, тексту EPUB и письменности. Для сканов без текста и латинских языков запрашивается ручной выбор.
- Конвертация запускается по одной группе языков; если книги на разных языках, следующую группу необходимо запускать отдельно.
- Восстановление архивов v1/v2 с manifest.json, а также старых архивов без manifest, если они содержат только data/, covers/, previews/. Перед восстановлением создаётся ZIP отката в data/.
- Обложки DJVU: первая страница через ddjvu (PNG/PPM), фоновое обновление при повторном сканировании. Требуется установленный ddjvu и Pillow.
- OCR модели ищутся в ocr/tessdata рядом с программой, а также в системной установке. Windows Portable: положите tesseract.exe, DLL и модели в ocr/.

## Важные ограничения
Это комплект исходников и сборки, не готовый Windows EXE или AppImage. Определение языка по письменности не равно полноценной лингвистической классификации. Русский/украинский, китайский/японский и латинские языки могут требовать подтверждения. Перед восстановлением делайте дополнительную внешнюю копию данных.
