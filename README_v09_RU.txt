Bee Library Collector v0.9

НОВОЕ:
- EPUB: порядок глав из OPF, изображения и встроенная читалка, закладки, размер шрифта и позиция чтения (хранятся в localStorage текущего браузера).
- Обложки по ISBN: Open Library Covers и Google Books (требуется интернет).
- Автопревью при импорте локальных PDF (первая страница), EPUB (обложка или первое изображение), CBZ (первое изображение), DJVU (при наличии ddjvu).
- Загруженная вручную обложка показывается первой; автоматически созданная остаётся второй и доступна через кнопку «Все обложки».

УСТАНОВКА:
1. Установите Python 3.10+.
2. Для генерации превью PDF установите: py -m pip install pymupdf pillow
3. Для изображений EPUB/CBZ: py -m pip install pillow
4. Для DJVU дополнительно установите DjVuLibre (ddjvu в PATH) и Pillow.
5. Запустите START_WINDOWS.bat.
6. Для обновления перенесите папки data, downloads, attachments, covers из v0.8. Новая папка previews создаётся автоматически.
7. Повторно просканируйте локальную папку для создания превью ранее импортированных файлов.

ОГРАНИЧЕНИЯ:
- Закладки EPUB и позиция чтения сохраняются в конкретном браузере, не синхронизируются между устройствами.
- EPUB с DRM не поддерживаются. Сложные интерактивные EPUB, нестандартные стили, вложенные шрифты и внешние ресурсы могут отображаться неполностью.
- Не все ISBN имеют обложки в публичных базах. Права на изображения и книги определяет правообладатель.
- EPUB с JavaScript не выполняется; документы показываются в изолированном фрейме.
- Генерация превью PDF требует PyMuPDF, DJVU — DjVuLibre. При отсутствии библиотек импорт файлов продолжает работать без превью.
