# Домашняя библиотека v2.6 — исправление группировки

Исправлено: распознавание совпадений названий при различиях в регистре, инициалах, названиях файлов и хвостах источников. Добавлен список похожих книг для ручной проверки во вкладке локальных книг. Исходные файлы не изменяются.

Важно: автоматически объединяются только очень близкие названия (порог 96,5%), одинаковые SHA-256 или ISBN при отсутствии противоречий по изданию. Разные годы/тома и неоднозначные названия не объединяются. В этом выпуске список спорных совпадений только для просмотра; ручное подтверждение объединения пока не реализовано.

Запуск и сборка: инструкции из предыдущего выпуска. Для запуска исходников установите зависимости из requirements.txt. Перед обновлением сохраните каталог data.
