Bee Library Collector v0.7

Запуск: START_WINDOWS.bat (Python 3.10+). Откройте http://127.0.0.1:8765.
Обновление: остановите старый сервер, распакуйте v0.7, перенесите data/, downloads/, attachments/ из v0.6. При наличии локальных обложек переносите covers/.

Новое:
- Крупные плитки и подробные карточки с обложкой, автором, годом, ISBN, аннотацией и ссылкой на источник.
- Загрузка обложки с диска (JPEG, PNG, WebP) либо с разрешённого HTTPS-источника.
- Сопоставление локальных файлов и карточек по ISBN, названию и автору. Предложения подтверждаются вручную.
- Просмотр PDF и TXT в браузере без обязательного скачивания. EPUB можно хранить и прикреплять, но для чтения нужен внешний ридер. DJVU/FB2/MOBI/AZW3 — внешний ридер.
- Предложение перевода названия на русский через внешний публичный сервис MyMemory, при недоступности — локальный словарь или ручное редактирование. Передаётся только название книги.
- Удаление типовых служебных префиксов (ebook), PDF, меток магазинов. Значимые слова реального названия НЕ удаляются автоматически.

Ограничения: алгоритм сопоставления эвристический и требует подтверждения. Сканирование защищённых/динамических сайтов может не извлечь все метаданные. Загрузка обложек разрешена только из добавленных источников, с проверкой сигнатуры изображения. Используйте обложки в соответствии с правами владельцев.
