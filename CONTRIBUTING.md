# Участие в разработке

Приветствуются отчёты об ошибках, улучшения совместимости Windows/Linux и предложения по качеству OCR.

Перед отправкой изменений:
1. Не включайте в коммиты личные книги, резервные копии, базы данных, ключи и чужие изображения.
2. Добавьте описание изменений и сценарий проверки.
3. Сохраняйте обратную совместимость каталога и резервных копий.
4. Учитывайте требования GPL-3.0 при использовании стороннего кода.

До публикации исходников v2.7 этот репозиторий содержит только организационные файлы.
