# Домашняя библиотека v2.5 — Фото → PDF + MD + RAG JSON

Вкладка Markdown / RAG → «Создать книгу из фотографий». Выберите локальную папку (на компьютере, где запущен сервер) с JPG/PNG/WEBP/TIFF/BMP. Файлы сортируются естественно: 1, 2, 10. Формируется PDF из фотографий с сохранением пропорций, book.md с OCR каждой страницы, rag_chunks.json, review_pages.json и отдельные изображения. Прогресс по страницам; готовый PDF открывается в браузере, весь комплект скачивается ZIP. Исходные фото не меняются.

Требуются Pillow, ReportLab, Tesseract OCR и языковые пакеты. Установка зависимостей сборки: pip install -r requirements-build.txt. Встроенная в PDF страница является изображением (не searchable PDF); полнотекстовый поиск доступен по MD/JSON. Для searchable PDF потребуется дополнительный слой OCR. Необязательно копировать фото в output — чекбокс.

Ограничения: 2000 изображений за задачу; OCR может ошибаться на фотографиях с бликами/искривлением; не выполняется автоматическое исправление перспективы и разворотов. PDF и результаты сохраняются в data/markdown_exports/photos_<id>. Отдельный фоновый процесс не блокирует пакетный конвертер книг. Не импортирует готовую PDF в каталог автоматически — это можно сделать обычным сканированием папки экспорта.
