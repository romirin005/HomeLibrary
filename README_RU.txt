МЕЖДУНАРОДНАЯ БИБЛИОТЕКА ПЧЕЛОВОДА — Bee Library Collector v0.6

ЗАПУСК
Windows: установите Python 3.10+ и запустите START_WINDOWS.bat.
Linux/macOS: python3 app.py
Адрес: http://127.0.0.1:8765
Сторонние библиотеки не требуются.

НОВОЕ В 0.6
1. Раздел «Локальные книги»: добавьте абсолютный путь к папке (например D:\\Books\\Beekeeping), включите подпапки. Сканируются PDF, EPUB, DJVU, DJV, FB2, MOBI, AZW3, CBZ, CBR, TXT, RTF, DOCX. Исходные файлы не копируются и не удаляются. При перемещении файлов ссылки потребуется обновить.
2. Раздел «Каталогизатор»: укажите URL магазина, нажмите «Получить карточку». Автоматически извлекаются доступные HTML OpenGraph и JSON-LD данные; не все магазины предоставляют метаданные. Можно заполнить поля вручную и сохранить карточку.
3. В каталоге у карточки нажмите «Прикрепить файл» (копирует выбранный файл в attachments/) или «Указать путь» (оставляет файл на прежнем месте). Для локальных книг доступна ссылка на файл.
4. CSV/XLSX экспорт включает библиографические поля и локальный путь.

СОХРАНЕНЫ
Поиск публичных PDF, Nongsaro/YES24, менеджер источников, словарь 19 языков, фильтры, журнал ошибок, экспорт, подтверждение прав на скачивание.

ВАЖНО
- Автоматическое чтение магазина зависит от его HTML, robots.txt и ограничений. При неудаче используйте ручное заполнение.
- Нет автоматического полного перевода названий на русский; есть словарь и ручное поле.
- В каталог можно заносить библиографические сведения о коммерческих книгах, но приложение не обходит DRM или платный доступ.
- Не открывайте локальный сервер в публичную сеть: он предназначен для использования на одном компьютере.
- Для сохранения каталога при обновлении переносите data/, downloads/ и attachments/.
