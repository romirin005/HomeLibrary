Домашняя библиотека v1.8 — Portable Build Kit

ИЗМЕНЕНИЯ
1. Перевод: если внешний сервис недоступен, открывается поле ручного ввода; заглушка «Требуется перевод» больше не предлагается к сохранению.
2. Каталог: 36 книг на странице, кнопки Первая/Назад/Вперёд/Последняя; новые книги вверху.
3. Единая версия 1.8 в заголовке, каталоге и разделе «О программе».
4. Счётчики PDF, DJVU/DJV, EPUB, TXT, DOCX и других форматов по данным каталога.
5. Дубликаты: нормализация служебных окончаний (1), Retail, сжатый, copy, форматов и похожих названий.

СБОРКА EXE НА WINDOWS
Распакуйте архив в папку без ограничений доступа и запустите build_windows.bat.
Требуется Python только на компьютере сборки и доступ к интернету для установки PyInstaller и зависимостей.
После сборки передавайте пользователю ВСЮ папку dist\HomeLibrary, включая _internal.
Для переноса существующей библиотеки заранее сохраните Backup, затем восстановите его в новой версии; файлы книг остаются на прежних путях.

ОГРАНИЧЕНИЯ
Онлайн-перевод зависит от доступности MyMemory. При недоступности доступно ручное сохранение русского названия.
Счётчики отражают зарегистрированные форматы, а не проверку физического наличия файлов.
EXE не собирался в Linux-среде; сборку и запуск необходимо выполнить на Windows.
