# Домашняя библиотека v2.0 — Linux / Windows

## Запуск без сборки (для разработчика)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install pymupdf pillow openpyxl
python app.py
```

Откройте http://127.0.0.1:8765. Для выбора папки через «Обзор» установите `zenity` или `kdialog`; также возможен tkinter. Путь можно ввести вручную.

## Сборка Portable на Linux

```bash
chmod +x build_linux.sh
./build_linux.sh
```

Результат: `release/HomeLibrary-v2.0-linux-<архитектура>-portable.tar.gz`. Распакуйте на целевой Linux-системе, запустите `HomeLibrary/run_linux.sh`. В составе находится Python-runtime. Собирайте отдельно для x86_64 и aarch64. Для максимальной совместимости собирайте на достаточно старом поддерживаемом дистрибутиве с совместимой glibc.

## Сборка AppImage

Установите официальный `appimagetool` в PATH (это инструмент **только сборочной машины**), затем:

```bash
./build_linux.sh --appimage
```

Результат: `release/HomeLibrary-v2.0-<архитектура>.AppImage`. AppImage не гарантирует работу на абсолютно всех дистрибутивах; возможны требования FUSE/системных библиотек. Проверяйте на целевых системах. AppImage использует `~/.local/share/HomeLibrary` или `$XDG_DATA_HOME/HomeLibrary` для изменяемых данных.

## DJVU

Встроенный просмотр требует `ddjvu` из DjVuLibre. На Debian/Ubuntu обычно `sudo apt install djvulibre-bin`; для внешнего просмотра — `xdg-open` и программа просмотра DJVU. Скрипт сборки **не включает** системные бинарные DjVuLibre в пакет. Для автономной поставки необходимо отдельно добавить совместимые `ddjvu` и библиотеки, протестировать их на целевых дистрибутивах и проверить лицензии.

## Совместимость с Windows

Windows EXE по-прежнему собирается `build_windows.bat` **на Windows**. Формат резервных копий v1.8 не изменён. Сами файлы книг не включаются в Backup; при переносе Windows → Linux потребуется переназначить пути или повторно сопоставить книги.

## Хранение и безопасность

Portable хранит `data`, `covers`, `previews`, `downloads`, `attachments` рядом с приложением (нужны права на запись). AppImage — в XDG-каталоге пользователя. Сервис слушает только `127.0.0.1`; не публикуйте его в сеть. Для восстановления данных используйте встроенный Backup. Прежде чем обновлять старую версию, создайте резервную копию.

## Известные ограничения

Графический выбор папки требует GUI-окружения. Встроенное чтение DJVU требует ddjvu. Интернет-поиск и перевод требуют подключения к сети. Реальный AppImage должен быть собран и протестирован на Linux; данный архив содержит исходники и скрипты сборки, а не заранее собранный AppImage.
