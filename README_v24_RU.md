# Домашняя библиотека v2.4 — группировка и анализ документов

## Что изменено
- Каталог: GET `/api/catalog/groups` возвращает объединения записей по SHA-256, ISBN или совпадению нормализованного названия, автора, года и ISBN. Исходные записи и файлы не меняются. В каталоге выводится одна карточка на группу, внутри — список экземпляров.
- Конвертер: `mode=auto|book|magazine|visual`, `save_page_images=true`, `review_uncertain=true`. Массовый запуск сохранён. Для PDF и DJVU сохраняются изображения страниц. В `review_pages.json` записываются страницы с подозрительно малым объёмом текста либо большим числом одиночных символов. В `metadata.json` — тип документа и число страниц на проверку.
- Определение журнала в auto — эвристика по количеству изображений и коротких страниц, НЕ полноценный анализ многоколоночной вёрстки. Это промежуточный механизм, не замена Docling/PaddleOCR. Точность OCR на сложных журналах не гарантирована.

## Важные ограничения
- Группировка без удаления, объединения метаданных и изменения исходных файлов. При ошибочном объединении записи остаются раздельными в `catalog.json`; для отдельного ручного исключения потребуется следующий этап.
- Автоматический анализ документа может ошибаться; сомнительные страницы сохраняются в JSON для проверки вручную. UI проверки по двум колонкам пока нет.
- Прогресс пакетной конвертации и карточки сохранён.
- Не переносите старые папки данных без резервной копии. Сборка EXE/AppImage выполняется в соответствующей ОС.

## Сборка
Windows: `build_windows.bat`. Linux: `chmod +x build_linux.sh && ./build_linux.sh --appimage` (нужен appimagetool).
OCR: Tesseract с языковыми моделями. DJVU: ddjvu + djvused.
