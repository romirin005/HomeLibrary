Bee Library Collector v1.2 — исправления чтения DJVU и отображения переводов.

1. После подтверждения русского перевода он становится главным заголовком, оригинал отображается ниже мелким шрифтом. До подтверждения главным остаётся оригинал.
2. Встроенный DJVU: программа ищет ddjvu.exe в PATH и стандартных каталогах DjVuLibre. Вывод PPM конвертируется в PNG для браузера.
3. При отсутствии DjVuLibre можно открыть DJVU во внешней программе Windows (если ассоциация файлов настроена).
4. Необходимость установки DjVuLibre для встроенного просмотра остаётся. Приложение не скачивает и не устанавливает системное ПО автоматически.

ОБНОВЛЕНИЕ: перенесите data, downloads, attachments, covers, previews из предыдущей версии. Перед переносом сделайте резервную копию data.
