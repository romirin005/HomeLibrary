# HomeLibrary v2.7.0 — первый публичный выпуск

Домашняя библиотека — локальное приложение для каталогизации и чтения электронных книг на Windows и Linux.

## Возможности
- Каталогизация PDF, EPUB, DJVU и других форматов, карточки и обложки книг.
- Группировка файлов одной книги, поиск похожих записей.
- OCR с Tesseract, преобразование в Markdown и JSON для RAG.
- Создание PDF из фотографий страниц и пакетная обработка.
- Резервное копирование и восстановление данных.

## Файлы
- **HomeLibrary-Windows-x64-Portable.zip** — распаковать целиком и запустить приложение из папки.
- **HomeLibrary-v2.7-linux-x86_64-portable.tar.gz** — переносимая Linux-сборка.
- **HomeLibrary-v2.7-x86_64.AppImage** — Linux AppImage (после скачивания выполнить `chmod +x`).
- **SHA256SUMS.txt** — контрольные суммы загружаемых файлов.

## Важно
Пакеты автоматически собраны в GitHub Actions. Для OCR и обработки DJVU могут потребоваться установленные в системе Tesseract и DjVuLibre. Прежде чем обновлять приложение, сохраните резервную копию пользовательского каталога. Сборки не имеют цифровой подписи.
