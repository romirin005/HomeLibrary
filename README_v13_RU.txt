Bee Library Collector v1.3

Запуск: START_WINDOWS.bat, затем http://127.0.0.1:8765.
Обновление: сначала резервная копия каталога. Перенесите из предыдущей версии data, downloads, attachments, covers, previews. Не копируйте старый app.py и index.html.

Изменения:
- Удаление служебных префиксов (ru), (en) и др. из отображаемого названия; оригинальное имя файла сохраняется.
- Перевод в фоне после импорта (галочка), сохранение в поле предложения. Утверждение индивидуально или пакетно.
- ISBN вводится в карточке; запрос Google Books/Open Library, выбор результата, предварительный просмотр и подтверждение правок. Отсутствие обложки не блокирует сохранение библиографии.
- Удобные отдельные поля названия и URL источника; каталог 28 предложенных сайтов по странам. Новые магазины отключены до явного включения.

Важно: онлайн-перевод использует MyMemory, который может быть недоступен или ограничивать частоту запросов. Не отправляйте приватные названия внешнему сервису. Пакетный перевод требует проверки человеком. Доступность ISBN-метаданных и автоматического сканирования магазинов не гарантируется. Данные книги не отправляются на перевод, только название.
