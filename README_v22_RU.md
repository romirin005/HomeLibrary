# Домашняя библиотека v2.2 — MD progress

- В карточке локальной PDF, EPUB, DJVU добавлена кнопка «MD — конвертировать книгу».
- В конвертере показываются общий процент, страницы текущей книги, число ошибок и успешных обработок.
- Обновление состояния выполняется каждые 1,2 секунды, без перезагрузки каталога.
- Исходные книги не изменяются.

## Предупреждение о памяти
Браузерное сообщение «Из-за нехватки памяти страница была перезагружена» может быть вызвано большой коллекцией карточек/изображений или нехваткой общей памяти. Индикатор конвертации сам по себе не устраняет эту причину. Для больших библиотек требуется виртуализация карточек и пагинация, а также ограничение разрешения изображений.

Сборка Windows: build_windows.bat; Linux: build_linux.sh --appimage.
