# Домашняя библиотека v2.3 — исправления

## Восстановление Backup

Загрузка ZIP теперь производится непосредственно из файла через HTTP POST `/api/backup/restore-file` (application/zip), без Base64 и чтения архива целиком в браузерную память. Максимальный размер входного ZIP — 4 ГиБ, распакованного содержимого — 8 ГиБ, одного файла — 2 ГиБ. Перед заменой файлов создаётся rollback ZIP. Восстанавливаются только каталоги `data`, `covers`, `previews`, с защитой от путей вне библиотеки. Для старых архивов с иной структурой может потребоваться отдельный адаптер; сохраните оригинал.

## PDF и OCR

OCR по-прежнему выполняется для всех страниц. Если существующий текстовый слой существенно полнее результата OCR, используется текстовый слой. Изображения, покрывающие более 68% площади страницы, считаются сканом страницы и не добавляются в Markdown как обычные иллюстрации. Остальные изображения сохраняются. У сложной вёрстки, OCR и таблиц остаются ограничения.

## DJVU

Скан каждой страницы остаётся в `images/` как контрольный оригинал, но в `book.md` не добавляется как иллюстрация каждой страницы. Для DJVU нужен DjVuLibre и Tesseract.

## Интерфейс

В карточке локальной PDF/EPUB/DJVU-книги есть блок Markdown/RAG. Кнопка создаёт MD, если его нет, или открывает текст прямо в карточке. Отображается прогресс, результат можно скачать ZIP. Массовая конвертация в отдельной вкладке сохранена. В списке экспортов отображаются названия книг и метаданные вместо одного ID.

## Сборка

Windows: `build_windows.bat`. Linux: `./build_linux.sh --appimage` или `./build_linux.sh`.

Перед обновлением сохраните копию каталога данных. Не удаляйте старую версию до проверки восстановления и конвертации на ваших книгах.
