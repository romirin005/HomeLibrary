# Домашняя библиотека v2.0 — Markdown / RAG

Вкладка **Markdown / RAG** позволяет выбрать локальные PDF, EPUB, DJVU и конвертировать их в `book.md`, `chapters/*.md`, `rag_chunks.json`, `metadata.json`, `images/*`. Результаты доступны в ZIP из интерфейса.

## Зависимости

Для PDF: PyMuPDF (включён в requirements-build.txt). Для OCR всех страниц: Tesseract OCR и языковые пакеты `rus`, `eng`. Для DJVU: DjVuLibre (`ddjvu`, `djvused`).

Ubuntu/Debian: `sudo apt install tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng djvulibre-bin`

Windows: установите Tesseract OCR с русским и английским языками, добавьте `tesseract.exe` в PATH; для DJVU установите DjVuLibre. Python-пакеты упаковываются PyInstaller, системные бинарники OCR/DJVU не входят в комплект.

## Ограничения

OCR выполняется для всех страниц PDF и DJVU; EPUB содержит собственный текст, OCR применяется ко встроенным растровым изображениям. Таблицы PDF извлекаются из структурной модели, но OCR не гарантирует восстановление таблиц на сканах. Главы определяются эвристически по заголовкам, их границы следует проверять. RAG JSON содержит фрагменты и номера страниц, но не эмбеддинги. Конвертация работает в одном фоновом потоке, без кнопки отмены; результат сохраняется в `data/markdown_exports`.

## Безопасность

Сервис слушает локальный интерфейс, обрабатывает только записи существующего каталога. Исходные книги не изменяются. Для OCR могут потребоваться существенные ресурсы; не конвертируйте всю библиотеку одновременно без проверки на нескольких книгах.
