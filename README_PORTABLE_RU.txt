ДОМАШНЯЯ БИБЛИОТЕКА v1.7 — PORTABLE ДЛЯ WINDOWS

1. В папке «Локальные книги» нажмите «Обзор…», выберите каталог и нажмите «Добавить и просканировать».
2. Чтобы собрать EXE, запустите build_windows.bat на Windows 10/11 x64 с установленным Python 3.11–3.13 и доступом в интернет.
3. После сборки скопируйте ВСЮ папку dist\HomeLibrary, а не только файл HomeLibrary.exe. На компьютере пользователя Python не нужен.
4. Запуск: двойной щелчок по HomeLibrary.exe. Интерфейс откроется в браузере на 127.0.0.1:8765.
5. Каталог, заметки, статусы, обложки и настройки хранятся рядом с EXE в папках data, covers, previews. Для обновления заменяйте файлы программы, но не эти папки. Сделайте Backup перед обновлением.
6. DJVU: встроенный просмотр требует ddjvu.exe и совместимые DLL. Их лицензии и включение в поставку нужно проверить отдельно; сборочный скрипт не упаковывает DjVuLibre. Внешний просмотр зависит от установленного ридера.
7. Важно: при запуске из Program Files запись данных может быть запрещена. Используйте доступную для записи папку, например Documents\HomeLibrary.
8. На другом компьютере пути к книгам должны оставаться действительными; сами книги в Backup не включаются.
9. Windows Defender/SmartScreen может предупреждать о неподписанном EXE. Для публичного распространения желательно подписать исполняемый файл.
10. Этот архив содержит ИСХОДНЫЙ КОД И СКРИПТ СБОРКИ, а не готовый Windows EXE.
