# Домашняя библиотека v2.7 — исправление запуска и схема релизов

## Что исправлено
- `START_WINDOWS.bat` и `start_windows.bat` создают локальное `.venv` и устанавливают **все** зависимости из `requirements.txt`, включая `reportlab` и `Pillow`.
- `app.py` загружает `photo_book_converter` только при вызове функции создания книги из фотографий; отсутствие необязательной библиотеки больше не блокирует старт сервера.
- `build_windows.bat` и `build_linux.sh` устанавливают зависимости из единого списка и явно включают ReportLab в сборку.

## Запуск исходников на Windows
Установите Python 3.11–3.13, распакуйте папку и запустите `START_WINDOWS.bat`. Первый запуск требует интернет для установки зависимостей. При ошибке проверьте, что Python поддерживает `venv` и `pip`.

## Создание Portable EXE
Запустите `build_windows.bat` **на Windows**. Раздавайте целиком папку `dist\HomeLibrary`, а не один EXE. Тестируйте на чистой машине. Tesseract и его языковые модели, DjVuLibre не встроены автоматически; их следует поставлять отдельно и проверять лицензии.

## Linux
На Linux запустите `./build_linux.sh` или `./build_linux.sh --appimage` (нужен appimagetool). Сборка Linux должна выполняться в Linux; проверьте системные зависимости.

## Данные
Перед обновлением скопируйте пользовательские каталоги `data`, `covers`, `previews`, `attachments` и экспортированные файлы. Не заменяйте их содержимым из архива исходников. Не распаковывайте обновление поверх работающего экземпляра.

## Обновления: рекомендованная архитектура
1. Версия в `version.json` и релизы на GitHub с ZIP для Windows/Linux, SHA-256 и `manifest.json`.
2. В приложении кнопка «Проверить обновления» читает публичный JSON по HTTPS и сравнивает версии. Проверка не должна скачивать и исполнять код без подтверждения.
3. Обновление скачивается в отдельную папку, проверяется SHA-256 (для защиты от подмены дополнительно подпись релиза), приложение останавливается, новая папка подменяет только код, данные остаются отдельно.
4. Перед миграцией БД создаётся backup; миграции версионируются и проверяются на копии. Откат на предыдущую версию должен быть доступен.
5. Автоматическая установка обновлений **не реализована** в v2.7; это план развития.

## Публикация исходников
Создайте репозиторий GitHub `HomeLibrary`, добавьте `LICENSE` (выберите лицензию осознанно), `README.md`, `CONTRIBUTING.md`, `.gitignore`, `requirements.txt`, исходники и инструкции. **Не публикуйте** `data/`, пользовательские книги, обложки с ограниченными правами, бэкапы, токены, `.venv/`, `dist/`, `build/`. Перед публикацией проверьте историю Git и права на включённые изображения и материалы.

## Проверка
Выполнены статическая проверка Python и проверка содержания ZIP. Компиляция Windows EXE и запуск на компьютере пользователя требуют отдельного тестирования.
