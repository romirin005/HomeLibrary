Bee Library Collector v1.0 — локальные метаданные

Новые функции:
- EPUB: Dublin Core из OPF (название, автор, издательство, описание, дата, идентификатор).
- PDF: свойства документа и текст первых 6 страниц (PyMuPDF).
- DJVU: текст через djvutxt (DjVuLibre), если он встроен в файл; OCR не выполняется.
- Поиск ISBN-10/ISBN-13 с проверкой контрольной цифры.
- SHA-256, дубликаты по хэшу, ISBN и похожему названию/автору.
- Сохранение уже отредактированных вручную полей.
- Русский перевод через существующую кнопку в карточке (внешний сервис при доступности).

Установите Python 3.10+ и по желанию: py -m pip install pymupdf pillow
Для DJVU: DjVuLibre, команда djvutxt в PATH.
Остановите старую версию и перенесите data, downloads, attachments, covers, previews.
Запустите START_WINDOWS.bat. Во вкладке Локальные книги нажмите Проанализировать все локальные книги.
Для сканов PDF/DJVU без текстового слоя необходим OCR, в эту версию он не входит.
Дубликаты не удаляются автоматически.
