Домашняя библиотека v1.5

Запуск: START_WINDOWS.bat (Python 3.10+). Откройте http://127.0.0.1:8765

Изменения:
- Новое название и порядок вкладок. Сканирование источников в «Источники и настройки».
- Раздел «О программе»: автор Роман, email romirin@gmail.com, персонаж в полный рост, локальный рекламный ролик.
- DJVU: рендер в отдельный временный файл с ограничением разрешения и времени, fallback PNG/PPM; внешний запуск через WinDjView, DjVuLibre или SumatraPDF при наличии.

Важно: для просмотра DJVU внутри браузера нужен ddjvu.exe из DjVuLibre. Для внешнего открытия нужна установленная программа чтения DJVU. Установка одной программы не гарантирует наличия ddjvu.exe.

При обновлении сохраните папки data, covers, previews, downloads, attachments из прежней версии.
